# 核を含む通常抽選30例

現代・SF・和風・研究施設・学園で各6例。トーン3・テーマなし・まとまり重視、各舞台でseedを固定して通常抽選し、核のある結果を記録。核の表示以外の抽選条件は変えていません。JSONのcoreは検証資料用の派生列で、アプリの保存には含めません。
