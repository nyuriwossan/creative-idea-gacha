# 本文を読んだ確認（Codex）

最終の36件を執筆・読み直し、全90件（各組30件）を読みました。表示ラベルと数値の判定とは分けて確認しています。新素材の助詞と接続に目立つ崩れはありません。約12件の追加に絞っているため、同じ灯り/点検/道しるべ/生データが繰り返し出る点は残ります。

## modern+fantasy

通勤定期/電気配線/共益費と術式が一緒に動く点から、まとまり重視15件では両方を感じ取れます。#3の祭り予算、#8の復讐/封印、#20の亡命と復讐など、別欄との物語上の接続は作者の補完が必要。#26は言霊の世界に現代の復旧担当が入るため、現代都市への移動/同じ社会の設定を足す必要があります。自由混合の#4/#10/#16/#22は魔法が本文に見えにくく、#18/#23/#29は現代側が弱い。タグ上の二舞台判定だけで強い反映とは扱いません。

## wafu+fantasy

旅籠/帳場/氏子/社/墨書と妖や術の関係が書かれ、まとまり重視15件では両方を感じ取れます。#38の研究対象、#51の帰りの切符は既存の別舞台要素が混ざる例で、妖を対象とする調査や現代的な要素を入れるか作者が決める必要があります。自由混合の#34/#36/#52/#54は本文にも和風と怪異が見えますが、#35/#48/#53/#58〜#60は和風が薄い。#54の装置校正と陰陽師の関係は自動でつながりません。
