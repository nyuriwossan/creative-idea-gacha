# 創作アイデアガチャ

世界観・関係性・葛藤から物語のタネを引き、自分で編集し、AIへの相談や創作へ持ち出せるツールです。

[公開サイト](https://nyuriwossan.github.io/creative-idea-gacha/)

## 使い方

1. 舞台・トーン・作品の用途を選び、「固定していない項目を引く」で基本7項目を引きます。テーマは最大3つ。設定変更だけでは素材は変わりません。
2. 気に入った項目を固定し、必要なら本文を編集します。主ボタンのすぐ下に「すべてのロックを外す」「テーマの選択を全解除」があります。内容は消さず、履歴で戻せます。
3. 基本7項目だけで使えます。人物・物語の進行・会話や1話の入口・質問回答は、必要な区画だけ開いて使います。開くだけでは抽選しません。
4. 結果の「AIに渡して続きを作る」で依頼文を作り、コピーして使いたいAIへ貼り付けます。ツールから外部AIを呼び出すことはありません。
5. 自分用の設定・構成メモは、従来どおりコピーやMarkdownで持ち出せます。保存名やメモを付けてブラウザにも保存できます。

編集欄の「反映」を個別に押さなくても、保存・コピー・現在JSON・Markdown・AI依頼文の更新時に、本文・短語・世界の背景・質問回答・人物名・保存名・タグ・メモをまとめて検証します。不正な入力があれば部分反映せず、該当欄へ移動します。入力は残るので直してから同じ操作をしてください。

## AIに渡す依頼文

作品の形式を選ぶ「出力用途」とは別に、AIへ頼みたいことを選べます。

| 依頼内容 | 求めるもの |
| --- | --- |
| 物語・プロット | 選んだ素材を活かす3案。本文は案を選んだ後 |
| AIチャット設定 | 世界・人物・関係・開始場面・進行ルール・導入案。確認前にRPを始めない |
| 壁打ち・深掘り | 設定のつなぎ方と質問を各最大3件 |
| 設定資料 | 保持内容・抽選素材・追加提案・未決を区別した資料 |

簡易／詳細を選べます。詳細は現在の用途別構成案も添えます。簡易でも選んだ素材や回答を省略しません。全文を選択できるプレビューと文字数を表示し、コピーに失敗した場合も手動コピー欄へ同じ全文を残します。

「現在の素材をすべて保持する」「不足する設定をAIに提案してもらう」は初期ON。「自由メモを含める」は初期OFFです。保持をOFFにしても抽選素材をまず活かし、変更は理由付きの提案として求めます。手入力は固定を外しても保持したい設定です。未回答や空の項目は省略し、背景チェックがないことを「存在しない」とは扱いません。

chatには任意の役割指定と追加条件があります。主人公＝ユーザーと勝手に決めず、集団や複数人物も扱います。同じ人物をユーザーとAIへ指定するとエラーを表示します。作者向けの秘密と公開する情報を分け、ユーザーの行動を代行しないよう依頼します。外部サービスの文字数上限や応答の遵守は保証しません。

## 抽選と素材

基本7項目・1,088素材・7用途・5トーン・20テーマ。人物は主人公／相手役それぞれ立場52、目的48、秘密48候補。進行は期限44、障害44、代償48、結末54候補。会話・1話の入口は共同目標／開始状況／小さな課題／次回の問いが各16候補。質問は4区分各26件です。

新規利用の「まとまり重視」は最大2つの題材と、葛藤・ひねりや場面の構造を手がかりに重みを付けます。「自由に混ぜる」は追加の題材・構造倍率を使いません。どちらも背景・トーン・固定・直前候補の除外とテーマ優先枠を守ります。条件に合う候補がある全体抽選では、基本3カテゴリ以上・主要2カテゴリ以上にテーマを反映し、選択した各テーマを使うよう配慮します。

第4回では「記録・記憶・証言の謎」「怪異と暮らし・共同ケア」「期限付き協力・共同契約」「職能・暮らしの技で解く」を追加しました。旧16テーマは維持しています。新規定義は基本144、入口64、共有人物28、進行28、質問12の計276件。共有人物は主人公・相手役へ展開し、定義数に二重計上しません。葛藤・ひねりの対応を12組追加しています。

世界の背景は旧8種に、自律AI・記憶や人格の保存編集・未来記録の3種を加えた11種。必要な背景を世界が明示した場合だけ候補を使い、選択テーマだけで魔法やAIの存在を決めません。手入力は背景を自分で指定します。背景・固定・トーンで候補が不足した場合は理由を表示します。日常ファンタジー＋破滅寄りの場合も、設定を勝手に変えず変更ボタンを案内します。

人物・進行・入口は区画ごとに抽選でき、基本の主抽選に巻き込まれません。各項目に固定・編集があり、編集欄内の「未設定に戻す」でクリアできます。質問は回答を反映すると固定し、ロックを外しても回答のある質問は通常抽選で消しません。次回の問いは余韻の候補で、会話の継続を強制しません。

抽選は設定や因果関係の完全な整合性を保証しません。個別の引き直しや編集で調整できます。

## 保存・バックアップ

- 同じブラウザ・サイトのlocalStorageへ保存します。クラウド、ログイン、APIキーは不要です。
- 「現在1件をバックアップ（JSON）」は編集中の変更も反映した現在のタネ。「保存済み作品すべてをJSON保存」は保存一覧だけで、現在の未保存編集は含みません。
- 全作品JSONの書き出し操作時刻と、その後の変更を案内します。実際のファイル保管を確認した時刻ではありません。5回の保存内容変更で案内し、AIコピー・現在JSON・Markdownでは日時を更新しません。
- 保存領域は `creativeIdeaGacha_v2`、schemaVersionは2。旧v2のAI設定と入口の欠損は安全な既定値・nullへ補います。旧保存の文章・回答・名前・固定を読み込みだけで再生成しません。抽選方針のない旧保存は「自由に混ぜる」です。
- 旧領域 `creativeIdeaGacha_state` / `creativeIdeaGacha_savedItems` は削除せず、移行前に `creativeIdeaGacha_legacyBackup` を残します。壊れたデータや未来版は上書きを止め、元データの取り出しを案内します。
- JSON取り込みは最大5MiB・500作品。既存作品を残して追加し、ID衝突は新IDへ分けます。容量不足で元作品を保存成功扱いにせず、現在のメモリからJSONやAI依頼文を持ち出せます。
- 履歴はセッション内で最大20スナップショット。AI設定・入口・解除操作も対象です。

## 開発と検証

ビルドや本番用依存はありません。ES ModulesのためローカルではHTTPサーバーを使います。

```sh
python -m http.server 8000
node --test tests/*.test.js
# 子プロセスの制約がある環境
node --test --test-isolation=none tests/*.test.js
```

`http://localhost:8000/` を開きます。GitHub Pagesはmainのルートを公開し、アセットは相対パスです。

ブラウザ確認には開発時だけPlaywrightを使います。

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/browser-check.cjs
```

`BROWSER_CHANNEL=chrome`、`PLAYWRIGHT_MODULE`、`TEST_OUTPUT_DIR`でブラウザや実行環境を指定できます。今回のNode検証61件、ブラウザ55項目、件数・トーン表・互換性・画面は[検証レポート](./VALIDATION.md)へ記録しました。実機iPhone／Safariは未検証で、スマートフォン相当のChrome表示と入力イベントによる確認です。

## 主な実装

- `js/ai-handoff.js` / `js/handoff-options.js`：依頼文の純粋関数・設定検証
- `js/scene-data.js` / `js/round4-data.js` / `js/round4-extra.js`：入口・新テーマ・横断素材・人物・進行・質問
- `js/core.js` / `js/cohesion.js` / `js/priority.js`：抽選・用途別構成案・履歴・テーマ優先枠
- `js/context.js` / `js/story-metadata.js`：背景と明示的な題材分類
- `js/drafts.js` / `js/storage.js` / `js/backup.js`：一括反映・保存・互換性・バックアップ案内
- `js/app.js` / `index.html` / `style.css`：画面・操作・コピー

外部AIへの自動送信・クラウド・作品題材の一律禁止フィルタは追加していません。
