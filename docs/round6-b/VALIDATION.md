# 抽象素材152件の追加（B）

基本104件（葛藤32・ひねり32・事件20・ギミック20）と場面48件（12組×4）を提示された本文・短語・トーンどおりに追加。元の基本1,457件、場面各16件のID・本文・全タグ・順序はそのままです。基本はdata.js末尾、場面は既存構成に合わせEXTRA_DATAの場面配列末尾へ連結します。SCENE_DATAの既存定義自体は変更しません。

専用11列/6列パーサーは空stage/context/themesを許し、不正列数・トーン・形・重複IDを拒否。8つの葛藤/ひねりキーと12の場面キーをknownLinksに登録。全舞台、各素材に指定された全トーン、背景なし/複数背景で候補入りを検証。提示素材はトーン1〜4のみのため、トーン5には追加候補を出しません。

抽選コード・重み・priority・stage-mix・storage・schema3は未変更。全152件の到達、本文出力、JSON往復、固定内容保持を検証。過去の素材/出力ハッシュテストは追加層だけを除いて以前の候補で比較し、元の期待値を維持。新テストは旧全定義の先頭一致と追加末尾一致、および抽選等6ファイルの完全一致を確認。核改修のソースハッシュは、追加のimport/concat/knownLinks接続だけを正確に除去して旧ハッシュを比較。

検証: Node全124件、ブラウザ全85項目成功。390pxを含む既存操作、保存、旧JSON、AI依頼文、核表示を確認。

## 1000回計測

リポジトリにusability-audit.mjsがなかったため、tests/usability-audit.mjsを追加。seed20261007、舞台すべて、トーン3、AIキャラプロットの種、まとまり重視、テーマなし、固定なし。基本と場面を毎回抽選し、recentと直前除外を維持。refreshTextsによる追加乱数は使いません。比較は同じseed・手順で追加前と追加後を各1000回。[生データ](./usability-audit.json)
