# 輪郭を待つ場所

舞台：現代 / トーン：シリアス / 用途：ショートストーリー向け
抽選テーマ：お任せ
抽選方針：まとまり重視
整理用タグ：なし

## 要約

舞台は「夜の歓楽街」。「工房に残る責任を持つ職人と、技術を外へ伝えたい旅人」という関係を軸に描く、「青春」のタネ。
物語の発端は「同じ量の食材なのに、作り方を変えた班だけ配れる食事の数が増える」。葛藤の核は「相手の夢を応援したいが離れるのは寂しい」。
望みがぶつかる場面で、何を選ぶのかを考えてみる。

## 設定と構成メモ

世界観：夜の歓楽街
ジャンル：青春
関係性：工房に残る責任を持つ職人と、技術を外へ伝えたい旅人
中心事件：同じ量の食材なのに、作り方を変えた班だけ配れる食事の数が増える
葛藤：相手の夢を応援したいが離れるのは寂しい
ギミック：直した箇所を拓本にして、次の職人へ渡す修理履歴
ひねり：会ったことがない恩人もこちらに救われていた

構成メモ｜ショートストーリー向け
以下は、選んだ素材を育てるための構成案です。
1. 発端：「夜の歓楽街」を舞台に、「同じ量の食材なのに、作り方を変えた班だけ配れる食事の数が増える」を物語の入口にする。
2. 行動と障害：主人公の目的を決める。目的を妨げる状況を考える。
3. 選択：「相手の夢を応援したいが離れるのは寂しい」を踏まえて、何を優先するか。手放す可能性のあるものを考える。
4. 変化・余韻：結末の方向を考える。ひねりの候補「会ったことがない恩人もこちらに救われていた」をどこまで明かすか決める。
5. 提案：短い期間や少ない登場人物に絞ると、ひとつの変化を描きやすい。

## 発想ヒント

「直した箇所を拓本にして、次の職人へ渡す修理履歴」を、道具・制約・日常の習慣のどれとして描けるだろう。

初めて協力できるのは、どんな小さな出来事のあとだろう。

同じ場面を別の立場から見ると、何が変わるだろう。

## タイトル案

- 輪郭を待つ場所
- 青春の輪郭
- 青春と帰り道
