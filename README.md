# 創作アイデアガチャ

現代プリセットは「選ばない」が初期状態で、選択を解除できます。舞台を問わない短い素材104件と、会話・1話の入口48件を追加しました。既存の素材と抽選の重みは維持しています。[追加素材の計測と確認例](./docs/round6-b/VALIDATION.md)

長い葛藤・ギミック・ひねり156素材に、短い「核」を表示します。「具体例を見る」を開くと元の本文を確認でき、編集では元の本文を直せます。AI依頼文や構成メモは核を中心にし、具体例も添えます。核は保存データへ追加せず、古い本文や手入力を置き換えません。


舞台を対等に2つ組み合わせられます。「舞台を組み合わせる（任意）」を開き、学園 × ファンタジー／現代 × 裏社会／裏社会 × ファンタジー／現代 × ファンタジー／和風 × ファンタジー／SF × 研究施設から選んで、通常の抽選ボタンを押してください。設定変更・解除だけでは本文は変わりません。「まとまり重視」は両方をつなぐ素材を優先し、現在の素材から反映状況を表示します。


世界観・関係性・葛藤から物語のタネを引き、自分で編集し、AIへの相談や創作へ持ち出せるツールです。

[公開サイト](https://nyuriwossan.github.io/creative-idea-gacha/)

## 使い方

1. 開くと基本7項目の結果が先に出ます。気に入らなければ下部の「固定以外を引く」で、固定していない項目を引き直します。
2. 舞台・トーン・作品の用途・テーマ（最大3つ）は、上部の設定チップ（または「設定」）から開くシートで変えます。設定変更だけでは素材は変わらず、次の抽選から反映します。設定要約のすぐ下にある「ロック解除」「テーマ解除」は、シートを開かずに1回で使えます（シート内の「すべてのロックを外す」「テーマの選択を全解除」と同じ動作）。ロック解除は基本7・人物・進行・入口と全区分の質問の固定を外し、テーマ解除は好みのテーマだけをお任せに戻します。どちらも再抽選はせず、本文・回答・名前・メモは消さず、1回の「戻す」で戻せます。固定やテーマが無いときは押せません。
3. 気に入った項目を固定し、必要なら本文を編集します。1項目だけ候補を見比べたいときは、カードの「他から選ぶ」で同じ条件の候補を10個並べ、1つ選んで使えます（選ばなかった候補は残りません。「戻す」で元に戻せます）。基本7項目だけで使えます。人物・物語の進行・会話や1話の入口・質問回答は、結果の下の「人物・進行・入口・質問を足す」から必要な区画だけ開いて使います。開くだけでは抽選しません。
4. 下部の「AIに渡す」で依頼文を作り、コピーして使いたいAIへ貼り付けます。ツールから外部AIを呼び出すことはありません。
5. 自分用の設定・構成メモは、従来どおりコピーやMarkdownで持ち出せます。保存名やメモを付けてブラウザにも保存できます。

編集欄の「反映」を個別に押さなくても、保存・コピー・現在JSON・Markdown・AI依頼文の更新時に、本文・短語・世界の背景・質問回答・人物名・保存名・タグ・メモをまとめて検証します。不正な入力があれば部分反映せず、該当欄へ移動します。入力は残るので直してから同じ操作をしてください。

## 世界観の使い方

世界観は時代・社会・暮らしの前提です。人物や事件は、ほかのお題と組み合わせて決められます。32件の本文とタイトル短語から、今回の恋人・事件・期限・結末の決めつけを外し、世界観249件・基本1,457素材のIDとタグ・抽選条件を保ちました。小さな店や都市、暗い環境の制約も残しています。

保存済み作品の本文・短語・固定・回答・作成済み出力は変わりません。世界観を引き直したときだけ新しい定義を使います。[変更前後・編集例・互換性と既存の候補不足](./docs/world-restructure-review.md)を記録しています。

## 現代ものから選ぶ

舞台選択の近くにある「現代ものから選ぶ」で、恋人・秘密の社内恋愛・仕事と恋愛の両立・警察・教師・医療・会社再建の7方向を選べます。選ぶだけでは変わりません。「この方向で引く」で基本の固定していない項目だけを引きます。

現在のトーン・用途・抽選方針を保ち、舞台は現代、テーマは選んだ方向の最大3つへ置き換えます。職業の背景を持つ世界観を先に選び、固定中の世界観が合わない場合は固定解除や背景編集を案内します。背景・トーン・直前除外は緩めません。未反映の編集を検証して、成功した編集と抽選は戻す1回で復元できます。必要な別世界がない場合でも、反映済みの作者編集は残します。今回のworld制約は通常ガチャへ持ち越しません。人物・入口・回答は任意です。

## AIに渡す依頼文

作品の形式を選ぶ「出力用途」とは別に、AIへ頼みたいことを選べます。

| 依頼内容 | 求めるもの |
| --- | --- |
| 物語・プロット | 選んだ素材を活かす3案。本文は案を選んだ後 |
| AIチャット設定 | 世界・人物・関係・開始場面・進行ルール・導入案。確認前にRPを始めない |
| 壁打ち・深掘り | 設定のつなぎ方と質問を各最大3件 |
| 設定資料 | 保持内容・抽選素材・追加提案・未決を区別した資料 |

簡易／詳細を選べます。詳細は現在の用途別構成案も添えます。簡易でも選んだ素材や回答を省略しません。全文を選択できるプレビューと文字数を表示し、コピーに失敗した場合も手動コピー欄へ同じ全文を残します。

「現在の素材をすべて保持する」「不足する設定をAIに提案してもらう」は初期ON。「自由メモを含める」は初期OFFです。保持をOFFにしても抽選素材をまず活かし、変更は理由付きの提案として求めます。手入力は固定を外しても保持したい設定です。未回答や空の項目は省略し、背景チェックがないことを「存在しない」とは扱いません。

chatには任意の役割指定と追加条件があります。主人公＝ユーザーと勝手に決めず、集団や複数人物も扱います。同じ人物をユーザーとAIへ指定するとエラーを表示します。作者向けの秘密と公開する情報を分け、ユーザーの行動を代行しないよう依頼します。外部サービスの文字数上限や応答の遵守は保証しません。

## 抽選と素材

基本7項目・1,761素材・7用途・5トーン・22テーマ。人物は主人公／相手役それぞれ立場86、目的48、秘密51候補。進行は期限44、障害44、代償48、結末54候補。会話・1話の入口は共同目標／開始状況／小さな課題／次回の問いが各28候補。質問は4区分各29件です。

これに加え、混合専用の新素材99件を選択ペアだけに追加します。既存素材の混合用注釈3件は、新規素材件数に含めません。

新規利用の「まとまり重視」は最大2つの題材と、葛藤・ひねりや場面の構造を手がかりに重みを付けます。「自由に混ぜる」は追加の題材・構造倍率を使いません。どちらも背景・トーン・固定・直前候補の除外とテーマ優先枠を守ります。条件に合う候補がある全体抽選では、基本3カテゴリ以上・主要2カテゴリ以上にテーマを反映し、選択した各テーマを使うよう配慮します。

第6回では現代の恋愛・会社・警察・医療・教育を扱う基本素材180件と質問12件を追加しました。「現代の恋人・会社もの」「職業もの」の2テーマ、会社・警察・医療・教育の4背景を追加し、テーマ22・背景15になりました。職業素材は世界観に必要な背景がある場合だけ候補になります。同居や遠距離など背景なしの恋愛も扱えます。現代恋愛・仕事の主役は成人を想定し、人物欄へ年齢や役割を自動入力しません。

第5回では舞台の生活・制度・仕事を含む基本素材189件を補い、全9舞台で世界観15件以上・各カテゴリ6件以上になりました。当時のテーマ20種・当時の背景11種・抽選の重みは維持し、葛藤とひねりの対応を30組接続しています。学園の破滅寄りには3世界を用意し、今回の整理では通学手段の制約・訂正の難しい成績記録・仮設教室の物資不足という前提へ直しています。トーン・背景を合わせるとまだ薄い候補プールもあり、全項目の舞台一致は保証しません。[追加前後の集計と検証](./VALIDATION.md)／[素材の接続例とAI依頼文12例](./docs/round5/MATERIAL-EXAMPLES.md)。

第4回では「記録・記憶・証言の謎」「怪異と暮らし・共同ケア」「期限付き協力・共同契約」「職能・暮らしの技で解く」を追加しました。旧16テーマは維持しています。新規定義は基本144、入口64、共有人物28、進行28、質問12の計276件。共有人物は主人公・相手役へ展開し、定義数に二重計上しません。葛藤・ひねりの対応を12組追加しています。

世界の背景は旧8種に自律AI・記憶や人格の保存編集・未来記録の3種と、今回の職業4種を加えた15種。必要な背景を世界が明示した場合だけ候補を使い、選択テーマだけで魔法やAIの存在を決めません。手入力は背景を自分で指定します。背景・固定・トーンで候補が不足した場合は理由を表示します。日常ファンタジー＋破滅寄りの場合も、設定を勝手に変えず変更ボタンを案内します。

人物・進行・入口は区画ごとに抽選でき、基本の主抽選に巻き込まれません。各項目に固定・編集があり、編集欄内の「未設定に戻す」でクリアできます。質問は回答を反映すると固定し、ロックを外しても回答のある質問は通常抽選で消しません。次回の問いは余韻の候補で、会話の継続を強制しません。

抽選は設定や因果関係の完全な整合性を保証しません。個別の引き直しや編集で調整できます。

## 保存・バックアップ

- 同じブラウザ・サイトのlocalStorageへ保存します。クラウド、ログイン、APIキーは不要です。
- 「現在1件をバックアップ（JSON）」は編集中の変更も反映した現在のタネ。「保存済み作品すべてをJSON保存」は保存一覧だけで、現在の未保存編集は含みません。
- 全作品JSONの書き出し操作時刻と、その後の変更を案内します。実際のファイル保管を確認した時刻ではありません。5回の保存内容変更で案内し、AIコピー・現在JSON・Markdownでは日時を更新しません。
- 保存領域は `creativeIdeaGacha_v2`、新規保存・JSON出力のschemaVersionは3。v2と旧形式を読み、v2は初回起動だけでは上書きせず、最初のv3書き込み前に専用v2RawBackupへ原文を退避します。旧版のアプリはv3を読み込めません。旧v2のAI設定と入口の欠損は安全な既定値・nullへ補います。旧generatedの背景はキー欠損時だけ候補IDから補完し、明示された空配列や手入力・legacyの本文から職業を推測しません。旧保存の文章・回答・名前・固定を読み込みだけで再生成しません。抽選方針のない旧保存は「自由に混ぜる」です。
- 旧領域 `creativeIdeaGacha_state` / `creativeIdeaGacha_savedItems` は削除せず、移行前に `creativeIdeaGacha_legacyBackup` を残します。壊れたデータや未来版は上書きを止め、元データの取り出しを案内します。
- JSON取り込みは最大5MiB・500作品。既存作品を残して追加し、ID衝突は新IDへ分けます。容量不足で元作品を保存成功扱いにせず、現在のメモリからJSONやAI依頼文を持ち出せます。
- 履歴はセッション内で最大20スナップショット。AI設定・入口・解除操作も対象です。

## 開発と検証

ビルドや本番用依存はありません。ES ModulesのためローカルではHTTPサーバーを使います。

```sh
python -m http.server 8000
node --test tests/*.test.js
# 子プロセスの制約がある環境
node --test --test-isolation=none tests/*.test.js
```

`http://localhost:8000/` を開きます。GitHub Pagesはmainのルートを公開し、アセットは相対パスです。

ブラウザ確認には開発時だけPlaywrightを使います。

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/browser-check.cjs
```

`BROWSER_CHANNEL=chrome`、`PLAYWRIGHT_MODULE`、`TEST_OUTPUT_DIR`でブラウザや実行環境を指定できます。今回のNode検証130件、ブラウザ88項目、件数・トーン表・互換性・画面は[検証レポート](./VALIDATION.md)へ記録しました。実機iPhone／Safariは未検証で、スマートフォン相当のChrome表示と入力イベントによる確認です。
