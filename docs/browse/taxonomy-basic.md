# 素材ブラウザーの分類（基本7項目）

「素材から選ぶ」で使う「大分類 → 小分類」の分類表です（2026-10-09 確認済み。件数の少ない枝は隣の枝へ統合）。素材の本文・抽選の重み・保存形式は変えていません。
1つの素材が2つの分類に入ることがあります（件数は分類ごとに数え、同じ素材は一覧で1回だけ出ます）。

複合舞台用の素材は、世界観では「複合舞台」の下にまとめ、ほかの項目では内容に合う分類に入れています（画面では「複合舞台用」の札で区別します）。
